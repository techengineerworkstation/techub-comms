# Tauri Icons

Generate icons using the Tauri CLI:

```bash
cargo tauri icon /path/to/your/icon.png
```

This will generate all required icon sizes:
- 32x32.png
- 128x128.png
- 128x128@2x.png
- icon.icns (macOS)
- icon.ico (Windows)
- icon.png (Linux)

Or use an online tool like https://tauri.app/v1/guides/features/icons/ to generate icons from a source image.
